# Repository Overview
---
This repository implements the analysis pipeline for paper [Distinct paths to false memory revealed in hundreds of narrative recalls](https://osf.io/sfqea_v1).

Authors: Phoebe Chen, Omri Raccah (co-first), Vy Vo, David Poeppel, Todd Gureckis

---

## 🧠 `A. script_prompting/`

This folder contains all scripts for the **LLM-based Annotation Pipeline**.
It transforms raw recall transcripts into structured model outputs.

### Files

* **`memory_classification_task.py`** — Runs GPT-based classification on each recall transcript, using story-specific prompts to label sentences while maintaining conversational memory.
* **`event_matching_task.py`** — Matches each classified recall sentence to its canonical event index using another GPT model and saves results to per-story Excel files.

### Subfolders

* **`memory_classification_prompts/`** — Holds per-story text prompts split into system instructions and example pairs for few-shot classification.
* **`event_matching_prompts/`** — Contains per-story system prompts guiding the model to return event indices for matching.
* **`story_segs.xlsx`** — Excel file defining the event lists for each story, used as reference during event matching.

## 📊 `B. read_GPT_output/`
### File

* **`read_GPT_output.py`** — Merges the GPT outputs, extracts categorical labels, populates analysis arrays, and stores them in `GPT_output/results_arrays`.

## 📊 `D. compute_semantic_features/`

This folder contains scripts for **computing semantic features** (prior knowledge, centrality, surprisal). The output is stored in `semantic_features/`.

### Files

* **`1A_narrativeXL_mpnet.py`** — Processes the NarrativeXL corpus into 55-word windows and embeds them using `all-mpnet-base-v2` to build a prior-knowledge corpus.
* **`1B_narrativeXL_USE.py`** — Does the same thing as above, but with Universal Sentence Encoder as the embedding model.
* **`2_compute_priorknowledge.py`** — Computes the average cosine similarity between story events and the NarrativeXL embeddings to estimate prior-knowledge strength per event.
* **`3. compute_centrality.py`** — Calculates within-story semantic centrality by averaging event-to-event cosine similarities using multiple embedding models.
* **`4. compute_surprisal.py`** — Measures contextual surprisal (token-level cross-entropy) for each event conditioned on prior context using GPT-2 or Pythia.

### Subfolders

* **`helper_files/NarrativeXL_embed/`** — Stores precomputed NarrativeXL embeddings (MPNet or USE), used as reference for prior-knowledge calculations.

## 📊 `E. semantic_analysis/`

This folder contains scripts for **integrating semantic features with behavioral outputs** for statistical modeling.

### Files
* **`1. create_dataframe`** — Aggregates all semantic measures and memory performance arrays into a single long-format dataset for mixed-model analysis.
* **`2. LLM_semantic_measures.rmd`** — R Markdown script performing GLMM analyses and generating coefficient plots linking semantic features to recall accuracy and error types.
* 
### Subfolders
* **`data_sheets/`** — Stores excels with all semantic measures and memory performance information.
---

## 📁 `GPT_output/`

This folder stores **model-generated outputs** from the prompting and classification stages.

### Subfolders

* **`memory_classification/{story}/`** — Per-story Excel outputs from the memory classification task.
* **`event_matching/{story}/`** — Event-indexed outputs from the event matching task.
* **`results_arrays/`** — NumPy arrays summarizing confabulation, factual errors, and inference presence per participant and event.
---

## 🧩 `semantic_features/`

This folder holds **derived semantic feature arrays** used for analysis.

### Files

* **`keep_ids.npy`** — Event indices to retain for each story.
* **`PriorKnowledge_allstories_*.pkl`** — Per-story prior-knowledge scores generated by `2_compute_priorknowledge.py`.
* **`centrality_*_*.npy`** — Semantic centrality vectors computed by `3. compute_centrality.py`.
* **`PPL_context_*_*.npy`** — Contextual surprisal arrays from `4. compute_surprisal.py`.
